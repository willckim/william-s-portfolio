3D Quote Engine

A white-label 3D configurator and instant quote tool that contractors embed on their own site with a 2-line snippet.

Drag the sliders, add the outdoor kitchen, download your quote.

Demo only, nothing you enter is sent anywhere.

The demo starts with the embed exactly as a contractor would paste it:

<script src="/demos/quote-engine/quote-builder-embed.js"></script>
<custom-quote-builder demo-mode></custom-quote-builder>

Problem

A contractor's website usually ends at a contact form. A visitor who wants to know what a pergola would cost, and how it would look, has to wait for a call back.

What I did

I built a configurator that runs inside the contractor's own site. The demo is a luxury louvered pergola with an optional outdoor kitchen. The price range updates live with an itemized breakdown, add-ons appear in the 3D scene, and the scene has day, sunset and night modes.

The visitor leaves with a branded PDF quote. The widget runs in Shadow DOM, so the host site's styles cannot break it.

How it works

One script tag and one element. Prices live in a config file beside the script, so a contractor changes a price without touching code.
